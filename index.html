Import / eksport danych

Excel, JSON oraz kopie bezpieczeństwa zapisywane na dysku komputera.

Dane jednej zakładki

Excel może używać polskich nazw kolumn. Dla danych przypisanych do oddziału możesz wpisać nazwę oddziału zamiast UUID. Najbezpieczniej pobrać najpierw „Wzór Excel”.

Migracja danych z wersji v45

Możesz wskazać bezpośrednio pliki JSON wyeksportowane ze starej wersji v45. Aplikacja rozpoznaje dokładne formaty v45: Eltrox-[region]-data.json (Eksport aktywnego regionu), Eltrox-wszystkie-regiony-data.json, Eltrox_backup_data.json, eksport Centrum raportowania oraz Porównywarki. Nazwy plików mogą zawierać inne daty – liczy się struktura JSON.
Ważne: import nie usuwa obecnych danych. Rekordy są dodawane lub aktualizowane. Przy eksporcie wielu regionów administrator może zasilić wszystkie regiony jednocześnie.
Uwaga o wizytach: standardowe eksporty JSON v45 nie zapisywały osobnej bazy raportów z wizyt. Jeżeli plik zawiera pole visitReports, v8.2 je zaimportuje; jeśli go nie ma, z samego eksportu v45 nie da się odtworzyć tych raportów.
